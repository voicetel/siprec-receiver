VoiceML integrations

To enrich a recording with the full calling record, the receiver fetches GET /2010-04-01/Accounts/{AccountSid}/Calls/{CallSid}.json from VoiceML when someone clicks Fetch full record on a call page. VoiceML API keys are per-account, so each account's key is stored here. Keys are write-only: they are never displayed after saving, and fetches use them only as the Basic-auth password.
